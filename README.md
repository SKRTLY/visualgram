# VisualGram: як отримати застосунок

VisualGram це Telegram для Android з чотирма доробками:

1. **Напівпрозорі бульбашки**: крізь повідомлення видно фон. Працює в усіх, хто встановив цей застосунок.
2. **Живі шпалери в чаті**: ти сам обираєш відео, і воно зациклено грає за бульбашками.
3. **Мої галочки**: замість стандартних галочок на твоїх повідомленнях стоїть серце, зірка, вогник тощо.
4. **Мій анімований подарунок на бульбашці**: ти перетягуєш його в потрібне місце на бульбашці.

Друзі з цим застосунком бачать твої галочки й подарунок на твоїх повідомленнях. Усе налаштовується в
**Налаштування → «Мод: шпалери, галочки, подарунок»**.

## Як зібрати APK (без Android Studio, на ноутбуці лише браузер)

**1. Ключі Telegram (безкоштовно).** Зайди на https://my.telegram.org, увійди за номером телефону, відкрий
*API development tools*, створи застосунок (назва `VisualGram`, коротка назва `visualgram`). Збережи
`api_id` (число) і `api_hash` (32 символи).

**2. Репозиторій на GitHub.** Створи акаунт на github.com, натисни *New repository*, назва `visualgram`,
вибери **Public** (за ліцензією GPL код має бути відкритий, якщо ти роздаєш APK друзям).

**3. Розпакуй архів `visualgram-mod.zip` і завантаж його файли в репозиторій** (*Add file → Upload files*, можна перетягнути все разом
із прихованою папкою `.github`):
`telegram-mod.patch`, `BASE_COMMIT`, `dummy-google-services.json` і папку `.github` з файлом
`workflows/build.yml`. Якщо папка `.github` не завантажилась: *Add file → Create new file*, у назві напиши
`.github/workflows/build.yml` і встав вміст файлу.
**Два файли `KEYSTORE_*.txt` (ключ підпису) я надіслав окремим повідомленням: на GitHub як файли їх не вантаж, вони потрібні лише для секретів у кроці 4.**

**4. Секрети.** В репозиторії: *Settings → Secrets and variables → Actions → New repository secret*.
Додай чотири секрети:

| Назва | Що вставити |
|---|---|
| `TG_API_ID` | твій `api_id` |
| `TG_API_HASH` | твій `api_hash` |
| `KEYSTORE_BASE64` | увесь вміст файлу `KEYSTORE_BASE64.txt` |
| `KEYSTORE_PASSWORD` | вміст файлу `KEYSTORE_PASSWORD.txt` |

**5. Запуск.** Вкладка *Actions → Build VisualGram APK → Run workflow*. Перша збірка триває
приблизно 30-60 хвилин, наступні швидші.

**6. Готовий файл.** Коли з'явиться зелена галочка, відкрий цей запуск, внизу в *Artifacts* скачай
`VisualGram-apk`, розпакуй zip, і всередині буде `app.apk`. Перекинь його на телефон і встанови
(Android попросить дозволити встановлення з невідомих джерел).

**7. Якщо збірка впала (червоний хрестик).** Відкрий крок, який позначений червоним, скопіюй останні
40 рядків помилки й надішли мені в чат. Код ще жодного разу не збирався, тож перші помилки
цілком можливі, і вони виправляються швидко.

## Важливо

- **Ключ підпису** (файли `KEYSTORE_*.txt`): збережи копію. Нова версія встановиться поверх старої лише
  з тим самим ключем, інакше доведеться видаляти застосунок і входити заново. Нікому його не віддавай.
  Якщо хочеш власний ключ, створи свій і заміни обидва секрети.
- **Вхід в акаунт.** Код підтвердження прийде в офіційний Telegram на іншому пристрої. Не входь у
  застосунок багато разів поспіль: Telegram тимчасово блокує вхід за надто часті спроби.
- **Сповіщення.** Без Firebase пуш-сповіщення від Google не працюють (збірка все одно проходить).
  За потреби створи безкоштовний проєкт на console.firebase.google.com, додай Android-застосунок з
  пакетом `com.visualgram.app`, завантаж `google-services.json`, перетвори його в base64 і додай як секрет
  `GOOGLE_SERVICES_JSON_BASE64`.
- **Невидимий знак.** Щоб друзі бачили твої галочки й подарунок, у кінець твоїх текстових повідомлень
  додається невидимий службовий знак. У звичайному Telegram він виглядає як порожній символ у кінці.
  У секретних чатах і в командах (`/start` тощо) він не додається. Вимкнути можна в налаштуваннях мода,
  пункт «Друзі».
- **Живі шпалери** постійно програють відео, тому беріть коротке відео без звуку, інакше швидше
  сідає батарея.
- Це сторонній клієнт, не офіційний Telegram. Не використовуй логотип і назву Telegram для нього.

## Що де змінено в коді

| Функція | Файл |
|---|---|
| Прозорість бульбашок | `ui/ActionBar/MessageDrawable.java` (метод `setAlpha`) |
| Живі шпалери | `messenger/mod/LiveWallpaperView.java`, `ui/ChatActivity.java` |
| Галочки та подарунки в бульбашках | `ui/Cells/ChatMessageCell.java`, `messenger/mod/ModTicks.java`, `ModGifts.java` |
| Невидимий знак для друзів | `messenger/mod/ModMarker.java`, `messenger/SendMessagesHelper.java`, `messenger/MessageObject.java` |
| Екран налаштувань | `ui/ModSettingsActivity.java`, `ui/SettingsActivity.java` |
| Назва, пакет, іконка | `strings.xml`, `gradle.properties`, `mipmap-*`, `drawable/icon_*` |
